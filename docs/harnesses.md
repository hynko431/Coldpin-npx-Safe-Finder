# Harnesses & Cross-Platform Distribution

`coldpin` maintains **one canonical skill source** under `skills/coldpin/` and **one compiled zero-dependency ESM runtime** under `lib/` (built deterministically from `src/` via `npm run build`). No agent harness receives a forked copy of the skill prose; host-specific runtime packages are compiled deterministically from the same source tree by `scripts/pack_plugin.py`.

## Antigravity App and Antigravity for IDEs

Build the clean allowlisted bundle with `python scripts/pack_plugin.py --target antigravity --verify` (or download `coldpin-antigravity.zip` + `SHA256SUMS.txt` from [GitHub Releases](https://github.com/hynko431/Coldpin-npx-Safe-Finder/releases)), extract it to a clean directory (without `.git/`), and install via the Antigravity CLI:

```sh
python -m zipfile -e dist/coldpin-antigravity.zip ./coldpin-antigravity
agy plugin install ./coldpin-antigravity
```

For workspace-scoped discovery inside this repository, run:

```sh
python scripts/pack_plugin.py --verify --sync-workspace
```

For manual installation without the CLI, extract `coldpin-antigravity.zip` into `~/.gemini/config/plugins/coldpin/` (remove any prior version first so stale files do not linger), then reload the window and verify `coldpin` appears in `agy plugin list`.

## Manifest Ownership & Drift Prevention

- Root `plugin.json` conforms strictly to `https://antigravity.google/schemas/v1/plugin.json` (`additionalProperties: false`, zero `"mcpServers"`, zero `"hooks"`, zero `"category"` at root) and is the single source of truth for plugin identity (`name`, `version`, `description`, `license`, `author`). MCP registration lives in root `mcp_config.json` (zero mandatory `variables` so public installs activate immediately; enterprises may apply `examples/mcp_config.private-registry.example.json`) for Antigravity and inline inside `.claude-plugin/plugin.json` for Claude Code; no root `.mcp.json` or `mcp.json` is emitted.
- `package.json`, `server.json`, `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `.codex-plugin/plugin.json`, `src/types.ts` (`ENGINE_VERSION`), `catalog/triage-rules.json`, `catalog/mcp-schema-pin.json`, `skills/coldpin/SKILL.md`, `skills/coldpin/skill-card.md`, `skills/coldpin-audit/SKILL.md`, and `skills/coldpin-incident/SKILL.md` (13 files total) are validated automatically against root `plugin.json` by `scripts/lint_skill.py` (any metadata or version drift fails lint).
- Runtime packages generated by `scripts/pack_plugin.py` enforce:
  - Explicit allowlist only (excludes `.git/`, `.github/`, `tests/`, `node_modules/`, `audit.jsonl`, `*.sqlite`, temporary artifacts) with Antigravity-only primitives (`rules/*.md`, `agents/*.md`, `hooks.json`, `skills/coldpin-{audit,incident}/SKILL.md`, `catalog/plugin.oms.sig`) scoped strictly to `HOST_GLOBS["antigravity"]`.
  - Zero symlinks, zero paths escaping repo root, zero automatic permission-approval hooks.
  - Sorted archive entries, fixed timestamp (`2026-01-01 00:00:00 UTC`), explicit POSIX metadata (`create_system=3`, `0100755` for `lib/{cli,mcp,mcp-http,hook}.mjs`, `0100644` otherwise), and byte-for-byte SHA-256 verification across two consecutive builds.
  - Relative Markdown link, HTML `href`/`src`, YAML asset, MCP `${PLUGIN_ROOT}` target, and `#heading-anchor` validation inside the packaged tree.

## Host Execution Boundaries

- Coldpin requires a local Node.js `>= 24.0.0` runtime (`git >= 2.25` for Git parity/bisect; Antigravity `>= v1.5.13` for `PreToolUse` hooks; Antigravity `>= v2.34.0` for inline MCP Apps). Cloud-only chat sessions without local process execution cannot run `lib/mcp.mjs` or `lib/cli.mjs` and must fail closed (`UNVERIFIABLE_UNKNOWN`) unless connected to a self-hosted `coldpin-mcp-http` gateway.
- Never install or enable automatic command-approval hooks (`auto_approve`, `permissionOverrides`, `overwrite`) for `coldpin`; the human user must explicitly approve any recommended `npx` command before execution.
- If an MCP host does not send `roots/list` to local `stdio` servers, set `COLDPIN_ALLOWED_ROOTS` (path-delimiter-separated absolute workspace roots) in the server `env` block to enable root-confined local file audits (`verify_confusion`, `audit_manifest_batch`, `audit_verify`).

## Optional Enterprise Extensions (`v1.6+` Phase E)

All Phase E extensions are strictly opt-in and preserve **$0/mo** maintainer cost and default local `stdio` zero-socket posture (`mcp_config.json` → `lib/mcp.mjs`):

- **Self-Hosted Streamable HTTP MCP Adapter (`lib/mcp-http.mjs` / `coldpin-mcp-http`):** Opt-in remote MCP server (`2025-11-25`) for enterprise VPCs, Cloud Run, or self-hosted gateways. Fails closed without `COLDPIN_HTTP_RESOURCE_URL` (`https://`) and `COLDPIN_HTTP_AUTH_MODE` (`oauth`, `api_key`, or `both`). Enforces OAuth 2.1 + PKCE (`S256`) + RFC 9728 Protected Resource Metadata (`/.well-known/oauth-protected-resource`) + RFC 8707 `aud` check + Antigravity CIMD (`https://antigravity.google/oauth/client-metadata.json`), pure Node 24 `RS256`/`ES256` JWKS verification (rejects `alg: none` and `HS*`), constant-time SHA-256 `cpk_live_*` API keys, anti-DNS-rebinding `Host`/`Origin` allowlists, `1 MiB` request cap, per-principal rate limiting, and principal-bound cryptographic `Mcp-Session-Id`. See `examples/mcp_config.http-remote.example.json` (OAuth CIMD, API Key, and Cloud Run `google_credentials`).
- **Inline Evidence Card MCP App (`ui://coldpin/evidence-card.html`):** Zero-dependency `text/html;profile=mcp-app` SEP-1865 (`io.modelcontextprotocol/ui`) UI linked via `_meta.ui.resourceUri` on `inspect_package_artifact`, `resolve_safe_anchor`, `verify_confusion`, and `audit_manifest_batch`. Enforces default-deny CSP (`csp: {}`), strict `createElement`/`textContent` DOM rendering (zero `innerHTML`/`eval`/external URLs), Antigravity `--color-*` host theme variables, copy-only command button, and read-only `get_artifact_report` paging. Hosts without MCP App support (CLI / IDEs) continue receiving compact plain-text/JSON responses automatically.
- **Disabled-by-Default Scheduled Weekly Audit Sidecar (`examples/sidecar.weekly-audit.example.json`):** Read-only Antigravity automation template (`"builtin": "schedule"`, `"restart_policy": "always"`, `"workspace_arg"`) whose `agent_permissions.access_grants` allow strictly `mcp(coldpin_coldpin/audit_manifest_batch)`, `mcp(coldpin_coldpin/verify_confusion)`, and `mcp(coldpin_coldpin/get_artifact_report)` with zero shell or file-write permissions. Copy explicitly to `~/.gemini/config/sidecars/coldpin-weekly-audit/sidecar.json` only when an organization wants recurring weekly scans.
