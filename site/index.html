Inspect npx packages cold. Pin clean releases.

Coldpin (coldpin v1.6.1) is a zero-dependency Node.js 24 CLI, local stdio MCP server (io.github.hynko431/coldpin), and native Antigravity plugin that vets npm tarballs in memory, verifies 3-tier tarball-to-source parity, and recovers pre-compromise release anchors without executing untrusted install scripts.

Antigravity Plugin Setup (5 Native Primitives)

Install directly via agy plugin install. Public installs activate on first click with zero mandatory variables, registering 3 skills (including /coldpin-audit and /coldpin-incident), 7 read-only aspect agents, 3 rules, 3 fail-safe PreToolUse hook groups, and 1 local stdio MCP server (1,643 eager tokens).

Antigravity CLI (macOS, Linux, Windows) 
agy plugin install https://github.com/hynko431/Coldpin-npx-Safe-Finder
agy plugin list
agy --agent coldpin-auditor

Inline MCP App Evidence Cards (Antigravity >= v2.34.0)

Tools inspect_package_artifact, resolve_safe_anchor, verify_confusion, and audit_manifest_batch automatically link ui://coldpin/evidence-card.html (SEP-1865, default-deny CSP, copy-only commands). Preview it live in the Interactive Policy Lab.

Standalone CLI & Local stdio MCP (npm)

Run Coldpin directly on Node.js >= 24.0.0 with zero runtime dependencies. Every CLI verb returns deterministic exit codes (0 clean, 2 suspicious/unknown, 3 malicious, 1 error) and supports --json, --sarif, and --sbom.

Pinned npm execution (never unpinned, scripts disabled) 
npx --ignore-scripts coldpin@1.6.1 inspect semver@7.7.1
npx --ignore-scripts coldpin@1.6.1 audit-batch ./package.json --limit 50
npx --ignore-scripts coldpin@1.6.1 mcp

Claude Code, Codex CLI & Official MCP Registry

Coldpin ships one canonical skill source (skills/coldpin/) and one compiled ESM runtime (lib/) across Claude Code, Codex CLI, Cursor, and the Official MCP Registry (io.github.hynko431/coldpin).

Verify checksums & extract host-targeted bundle 
sha256sum -c SHA256SUMS.txt
python -m zipfile -e coldpin-claude.zip ./coldpin-claude
python -m zipfile -e coldpin-openai.zip ./coldpin-openai

Self-Hosted HTTP MCP & Air-Gapped Enterprise

For centralized VPCs, Cloud Run gateways, or air-gapped CI runners, run the opt-in Streamable HTTP adapter (coldpin-mcp-http) with fail-closed OAuth 2.1 CIMD / SHA-256 API keys, or enforce strict offline tarball inspection via COLDPIN_OFFLINE=1.

Air-gapped offline tarball inspection (zero outbound traffic) 
COLDPIN_OFFLINE=1 node --no-warnings lib/cli.mjs inspect \
  --tarball ./vendor/pkg.tgz \
  --git-dir ./vendor/repo \
  --offline --sarif --audit-log ./audit.jsonl

Defense-in-Depth Architecture

Coldpin separates untrusted package content from deterministic static analysis and human execution authority across four strict trust boundaries:

Native Guardrails (rules/, agents/, hooks.json)Read-only aspect subagents (commandExecutionPolicy: "off"); pure ES2020 PreToolUse hook exiting 0Routes 6 security aspects across isolated subagents, blocks evasive package runners, and forces confirmation on pinned runs, config edits, and writable subagents.
Agent Skills (skills/)Untrusted package READMEs & metadata isolated as data; fail-closed on unknownsOrchestrates all 7 MCP tools / 6 CLI verbs with 5 aspect playbooks plus /coldpin-audit and /coldpin-incident slash commands.
Human OperatorExplicit approval gate before any host executionReviews observations, inferences, unknowns, and stock-npx transitive caveats before approving any pinned command.
