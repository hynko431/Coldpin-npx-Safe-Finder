CLI Reference & Exit Codes

Both the standalone CLI (lib/cli.mjs / coldpin) and the MCP servers execute the exact same pure async workflows under src/core/workflows.ts.

AVAILABLE ON: Standalone CLI GitHub Actions / CI Node.js >= 24

6 Canonical CLI Verbs (+ mcp Dispatch)

Mobile view
CLI VerbMCP EquivalentExit CodesDescription
discover [query]discover_packages0 / 2 / 1Search npm by capability, category, org, or creator with org allow/deny policy, release cooldown, and 7-primitive typosquat/slopsquat filters.
inspect <pkg[@ver]>inspect_package_artifact0 / 2 / 3 / 1Zero-execution tarball inspection, SHA-512 check, lexical JS/TS taint, hidden-Unicode scan, OSV/MAL-*, and 3-tier tarball-to-Git parity.
resolve-anchor <pkg>resolve_safe_anchor0 / 2 / 3 / 1Walk --first-parent Git history with blob-cached SQLite scans to locate patient-zero and verify a clean npm tarball rollback or alternative.
verify-confusion [path]verify_confusion0 / 3 / 1Audit package.json and .npmrc for unpinned private scopes and claimable internal names (T1195.001).
audit-batch [path]audit_manifest_batch0 / 2 / 3 / 1Batch-screen up to 50 direct dependencies from package.json with private-scope OSV non-leakage.
audit-verify <jsonl>audit_verify0 / 3 / 1Verify sequence continuity, extra-field tamper protection, and SHA-256 hash chain of local audit.jsonl files.
mcpServer entrypoint0 / 1Start local zero-dependency JSON-RPC 2.0 stdio MCP server (lib/mcp.mjs).

Deterministic Exit Codes

Mobile view
Exit CodeMeaningTypical Verdicts / CI Action
0Clean within scope / PassVERIFIED_CLEAN_WITHIN_SCOPE, USE_PINNED_LATEST, valid audit.jsonl, --version / -V
2Suspicious, quarantined, or unverifiableQUARANTINE_SUSPICIOUS, UNVERIFIABLE_UNKNOWN, FORENSIC_COMMIT_ONLY — fail closed in CI until reviewed
3Malicious indicators or policy blockMALICIOUS_INDICATORS_FOUND, dependency confusion found, tampered audit.jsonl — halt build immediately
1Invalid usage or operational errorUnknown flag, missing required value, Node < 24, or unreadable local target
