7 Read-Only Aspect Agents & 3 Rules

Every Coldpin security aspect runs inside an isolated read-only subagent with private body rules, commandExecutionPolicy: "off", and a scoped Coldpin MCP tool allowlist enforced by SS-14-AGENT-LEAST-PRIV and SS-15-RULES-HYGIENE.

Why background subagents set inheritCustomizations: false ([PLG-15])

When auditing an untrusted cloned repository, malicious .agents/rules/ or workspace hooks inside that repository must never hijack Coldpin's specialist workers. Setting inheritCustomizations: false isolates all 6 leaf workers from untrusted workspace overrides.
