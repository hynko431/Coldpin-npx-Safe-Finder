v1.6.0 — 2026-11-23 Latest

Added

  • Opt-In Self-Hosted Enterprise Streamable HTTP MCP Adapter (`src/mcp-http.ts` → `lib/mcp-http.mjs`, `src/mcp/http-auth.ts`, `src/mcp/http-server.ts`, `examples/mcp_config.http-remote.example.json`): Added an isolated, fail-closed Streamable HTTP MCP (2025-11-25) adapter (bin.coldpin-mcp-http, POSIX 0100755) keeping default mcp_config.json / lib/mcp.mjs local stdio-only with $0/mo maintainer cost. Enforces OAuth 2.1 + PKCE (S256) + RFC 9728 Protected Resource Metadata (/.well-known/oauth-protected-resource and path-inserted form) + RFC 8707 aud & scope (403 insufficient_scope) validation + pure Node 24 RS256/ES256 JWKS verification (rejecting alg: none and HS*, with SSRF-guarded fetchJwksJson() consolidated inside src/intel/registry-osv.ts), constant-time SHA-256 cpk_live_* API keys (rejecting <32-char keys and unexpanded ${VAR} placeholders), anti-DNS-rebinding Host + Origin allowlists, 1 MiB request body cap (413), per-principal rate limiting (429 + Retry-After), principal-bound cryptographic Mcp-Session-Id (403 on cross-principal reuse, DELETE /mcp 204), and Cloud Run google_credentials config template.
  • Zero-Dependency Inline MCP App (`ui://coldpin/evidence-card.html`, `src/mcp/evidence-card-app.ts`): Added a self-contained text/html;profile=mcp-app SEP-1865 (2026-01-26) JSON-RPC postMessage evidence card UI linked via _meta.ui.resourceUri on inspect_package_artifact, resolve_safe_anchor, verify_confusion, and audit_manifest_batch, with io.modelcontextprotocol/ui initialize negotiation, default-deny CSP (csp: {}, default-src 'none'), strict createElement/textContent DOM rendering (zero innerHTML, eval, or external URLs), Antigravity --color-* host theme variables, copy-only command button, and read-only get_artifact_report paging while holding tools/list at 1,628 <= 1,800 estimated tokens.
  • Disabled-by-Default Scheduled Weekly Audit Sidecar Template (`examples/sidecar.weekly-audit.example.json`): Added an opt-in Antigravity automation template ("builtin": "schedule", "restart_policy": "always", "workspace_arg") whose agent_permissions.access_grants are strictly limited to read-only Coldpin MCP tools (audit_manifest_batch, verify_confusion, get_artifact_report) with zero shell/write permissions and zero active sidecars/ directory at plugin root.
  • Phase E Verification, Self-Audit Rules & README Badges (`tests/phase-e-http-and-app.test.ts`, `scripts/self_audit_skillspector.py`, `scripts/run_benchmarks.ts`, `README.md`): Added deterministic live loopback OAuth/JWKS/API-key/HTTP/MCP-App/sidecar tests (42/42 across 7 suites), 3 new mutation proofs (mut-36–mut-38, 38/38 total), SkillSpector rules SS-16–SS-18 (APPROVE, risk=16/100, 0 blocking across 24 compiled ESM modules), and GitHub Light/Dark adaptive mcprush.com score.svg + card.svg badges.
